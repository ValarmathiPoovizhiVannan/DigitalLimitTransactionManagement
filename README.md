# Digital Payment Limit Management

## About
**Digital Payment Limit Management** is a Java web application to manage account transactions with daily limits.  
It uses **Servlets** and **JDBC** without any frameworks.

---

## Technologies
- Java 21
- Apache Tomcat
- MySQL
- Maven
- JUnit
- JaCoCo
- SonarQube
- Postman
- JDBC
- Jakarta Servlet 

---

## Features
- Create and view accounts
- Credit and debit money
- Store transaction history
- Validate transactions

---

## Testing
- Unit testing with JUnit
- Code coverage with JaCoCo
- API testing with Postman
- Code quality analysis with SonarQube
